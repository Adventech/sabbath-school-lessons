---
title:  "Thucah siatsuahnak: Then 1"
date:   09/11/2026
---

`Siar ding: Jeremiah 36:20-26. Thuthennak hmun ah ziang thil a thleng, hruaitu pawl in profet simcia ralrinnak ziangtin an let?`

Jeremiah cu Judah miphun pawl an tluksiat lai caan ih Pathian simcianak au-aw a si. Kum tamzet cu Pathian cun Jeremiah hmangin Judah pawl parih a lungawi lo thu le Babilon in an neh dingih salah an hruai ding ti tiangin ralrinnak a rak pe a si (Jer. 6:8-19, Jeremiah 26). Bawipa cun rundam a duh, asinan annih cun an rak ngai duh lo.

Judah pawl ih sualnak cu a nasa tuk, a danglam ve lo. Milem biaknak, fahniang raithawinak, nupa sualnak, thuthennak dik lo tivek pawl cu Jeremiah san ahcun thil fehdan phung a si. Asinan Jeremiah ih ralrinpeknak le ngennak cu zianghman ah an siar lo. Jeremiah ih profet simcianak hnatuan a cem zawng ah Pathian in a fale zin dik lo ih a fehtu pawl hrangih a ngennak cu a nasa deuhdeuh, Pathian cun annih cu tlen a duh ringring. Thimnak ah Jeremiah 32 ahhin Pathian cun Jeremiah hnenah loram pakhat lei dingin le fekzetih thil ti dingin a sim, “ ‘Ralkap pawl ih Bawipa in hitin a ti… “Inn, le lo, le sabit hmuan pawl cu hi ram sungah neihsal an si ding, tiin’ ” (Jer. 32:15, NKJV).

Jeremiah hnenah Sualsirnak le tuahthatsal awknak hrangih ngennak netabik ngan dingih Pathian cangvaitertu bik cu Duhdawtnak hi a si. Jehoiakim cun himi thucah, Pathian le A thucah le A thucah kengtu cu hmuhsuam zetin a let a si.

`Siar ding: Jeremiah 36:27-31. Jehoiakim ih cangvaihnak cu Pathian in ziangtin a let?`

Khuimaw caan ahcun Pathian ih thucah kan siatbal asilole kan hnong asilole a thucah kengtu pawl kan rak hnong a si ahcun a thucah copcilh in a hlo mai ding timi zumnak a um theu. Pathian profet simcianak tongkam kan ngai duh lo ruangah kan hrang Pathian thucah cu a hloral cuang lo. Kan hmuhsuamnak cun kan lungruh ruangah simaw kan dokalh ruangah simaw kan sungkua le kan parah harsatnak a thlen deuhdeuh ding a si. Siangpahrang Jehoiakim ih netnak thu Jeremiah ih simcianak cun minung hmuahhmuah hrangah ralrin peknak rapthlak zet a nei (Jer. 36:30, 31): Pathian ih ralrin peknak kan thlahthlam asile kan sualnak le kan thil thalo tuahnak ih a rah cu kan khawm tengteng ding a si.

`A mipi pawl in an dokalh rero cing hmanih, an hnen thlen thei dingih a zuamnak ahhin Pathian ih duhdawtnak thawn pehpar in ziang so in sim?`
